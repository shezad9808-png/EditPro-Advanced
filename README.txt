EDITPRO ADVANCED — FREE BROWSER EDITOR

FILES
- index.html: the app. No Node.js or build step required.

RUN ON PC
1. Extract this ZIP.
2. Open index.html in current Chrome or Edge.
3. Select a photo or video.

NEW PHOTO FEATURES
- Quick looks: Original, Vivid, Warm, B&W, Fade
- Brightness, contrast, saturation, grayscale, sepia, blur
- Rotate and horizontal flip
- Caption/watermark text with position, colour, size
- JPG/PNG export and JPG quality setting
- Optional preview-size export for smaller files

VIDEO FEATURES
- Video preview, playback speed, brightness/contrast/saturation preview
- Select clip start and end
- Experimental WebM clip recording/export where browser support permits

IMPORTANT LIMITATIONS
- This is a free starter project, not yet a full multi-track CapCut replacement.
- Video export is experimental, browser-dependent, outputs WebM (not MP4), and may not preserve audio on all devices.
- For GitHub Pages, upload index.html at the repository root, then Settings > Pages > Deploy from a branch > main > /(root) > Save.
- Do not upload private or sensitive photos to a public repository. The app source is public if using GitHub Pages; your selected media is processed locally in the browser and is not uploaded by this code.
